# session-restore

재부팅 전 **저장할지 묻기** → 적기 → 재부팅 → **다시 열지 묻기** → 열기 → 떴는지 확인.

재부팅하면 도는 Claude 세션이 전부 꺼진다. 대화 기록은 남아서 `claude --resume <세션 ID>` 로
이어 열 수 있지만, 어느 tmux 창에서 어느 디렉터리로 무슨 옵션으로 돌던 것인지는 재부팅 뒤에 알 수 없다.
그래서 재부팅 직전에 적어 둔다.

| 원래 자리 | 다시 여는 곳 |
|-----------|--------------|
| tmux 안 | 같은 이름의 tmux 세션 |
| 그냥 터미널 | Claude 세션 이름으로 새 tmux 세션 (`.`·`:` 은 `-` 로, 겹치면 `-2`) |

그냥 터미널에서 돌던 세션도 창이 아니라 tmux 세션으로 연다. 그래픽 화면에 로그인하지 않아도, SSH 로만 붙어 있어도 열린다.
사용자는 `tmux attach -t <이름>` 으로 들어간다.

## 절대 규칙

1. **할지 먼저 묻는다.** 저장도 복원도 묻지 않고 하지 않는다. 사용자가 원하지 않는 세션을 되살리면
   그 세션이 다시 작업을 시작한다.
2. **재부팅 직전에 적는다.** 앞서 적어 둔 기록은 그 뒤에 열고 닫은 세션을 모른다.
   재부팅 승인을 받는 그 턴에 다시 적는다.
3. **"엶" 은 떴다는 뜻이 아니다.** `restore.sh` 의 마지막 확인(패널에서 claude 가 도는지)까지 보고 말한다.

## 1. 재부팅 전 - 저장할지 묻기

재부팅·전원 끄기를 실행하기 전에 지금 무엇이 적힐지 본다. 적지는 않는다.

```sh
~/.claude/skills/session-restore/scripts/snapshot.sh -n
```

재부팅 승인을 받는 질문에 한 줄을 같이 넣는다. 따로 묻지 않는다.

> 재부팅하면 Claude 세션 6개(do-test-bc, mon2-a1, ...)가 꺼집니다.
> 재부팅 뒤 tmux 세션으로 같은 디렉터리에서 다시 열 수 있게 적어 둘까요?

| 답 | 행동 |
|----|------|
| 적어 둔다 | 재부팅 명령 바로 앞에 `snapshot.sh` 를 실행하고 몇 개를 적었는지 알린다 |
| 안 적는다 | 적지 않는다. 앞서 적어 둔 기록은 그대로 둔다 |
| 도는 Claude 세션이 없음 | 묻지 않는다 |

```sh
~/.claude/skills/session-restore/scripts/snapshot.sh
```

기록은 `${CLAUDE_CONFIG_DIR:-~/.claude}/session-restore/last.tsv` 에 남는다. 지금 이 세션도 같이 적힌다. 재부팅 뒤 이어서 할 일이 있으면 진행 파일에 적어 둔다.

## 2. 재부팅 뒤 - 다시 열지 묻기

"다시 띄워" 같은 요청이 오면 무엇이 열릴지 먼저 보인다.

```sh
~/.claude/skills/session-restore/scripts/restore.sh -n
```

> 11-20 01:40 에 적은 기록입니다. 이 6개를 엽니다: ...
> 이미 열려 있는 대화와 같은 이름의 tmux 세션이 이미 있는 것은 건너뜁니다. 열까요?

`restore.sh` 는 지금 도는 claude 의 세션 ID 를 `~/.claude/sessions/` 에서 읽어, 이미 열려 있는 대화는 건너뛴다.
재부팅 뒤 사용자가 먼저 손으로 연 세션이 기록에 다른 tmux 이름으로 있어도 같은 대화를 두 번 열지 않는다.

사용자가 "지금 다시 띄워" 처럼 열라고 분명히 말했으면 목록만 보이고 바로 연다. 일부만 열라고 하면
기록을 복사해 그 줄만 남긴 파일을 인자로 넘긴다. 원래 기록은 고치지 않는다.

```sh
~/.claude/skills/session-restore/scripts/restore.sh
```

## 3. 떴는지 확인

`restore.sh` 는 연 세션마다 15초까지 패널의 현재 명령이 `claude` 로 바뀌는지 본다. 종료 코드 0 이면 전부 떴다.
`claude 가 안 보임` 이 나온 세션은 `tmux capture-pane -p -t =<이름>:` 로 화면을 읽어 무엇이 막았는지 보고한다
(세션 ID 가 없어짐, 디렉터리 권한, 로그인 만료 등).

## 하지 말 것

- 묻지 않고 적거나 열기
- 재부팅 승인을 받기 전에 적어 두고, 그 사이 바뀐 세션을 모른 채 재부팅하기
- 같은 이름의 tmux 세션이 있는데 죽이고 다시 만들기
- `엶` 만 보고 떴다고 보고하기
- 원격 호스트 재부팅에 이 skill 을 쓰기 (그 호스트의 세션은 여기서 안 보인다)
