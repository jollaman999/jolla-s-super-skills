## 작업

| # | 작업 | 완료 조건 (관측 가능) | 건드릴 파일 | 의존 | 위험 |
|---|------|----------------------|-------------|------|------|
| 1 | | | | - | 안전 |
| 2 | | | | 1 | 안전 |

**완료 조건은 관측 가능해야 한다.** "잘 동작한다" 가 아니라 "이 명령을 돌리면 이 출력이 나온다" 로 쓴다.

| 나쁜 조건 | 좋은 조건 |
|-----------|-----------|
| 알림이 잘 간다 | 임계치 초과 1건 후 슬랙 목 서버에 POST 1건이 들어온다 |
| 설정이 반영된다 | 잘못된 임계치로 기동하면 exit 1 과 에러 메시지가 나온다 |
| 성능이 개선된다 | 1000건 처리가 기존 8초에서 3초 이하로 떨어진다 |

**위험**은 `안전` / `주의` / `위험` 이다. 되돌리기 어려운 것(스키마 변경, 데이터 삭제,
원격 재기동, 인터페이스 변경)이 `위험` 이고, 그 작업 차례에 따로 승인받는다.
