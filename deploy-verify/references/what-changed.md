# 무엇을 바꿔야 반영되나

배포 전에 판정한다. **여기서 틀리면 "고쳤는데 반영이 안 됨" 이 된다.**

## 재빌드냐 파일 교체냐

같은 repo 안에서도 파일마다 다르다. 마운트된 것은 교체+재시작이면 되고, 이미지에 들어간 것은 재빌드해야 한다.

> Config / example / operator 변경 = 마운트된 파일 수정 + 재시작
> **Go 코드 변경(예: `gusty.go`) = 이미지에 컴파일됨, 마운트 아님 -> 반드시 재빌드**

### 판정 방법

```sh
# 1) 컨테이너의 마운트 목록을 본다
docker inspect <c> --format '{{range .Mounts}}{{.Source}} -> {{.Destination}}{{println}}{{end}}'
# 2) compose 파일의 volumes 를 본다
grep -A20 'volumes:' docker-compose.y*ml
```

내가 고친 파일의 컨테이너 안 경로가 **마운트 아래 있으면** 파일 교체, **없으면** 재빌드다.

| 바꾼 것 | 대개 | 확인 |
|---------|------|------|
| 설정 파일 (`*.yaml`, `*.conf`, `.env`) | 마운트 -> 교체 + 재시작 | 마운트 목록에 있나 |
| 예제·템플릿·플레이북 | 마운트 -> 교체 | 위와 동일 |
| 컴파일 언어 소스 (Go, Java, Rust) | **재빌드** | 바이너리/jar 가 이미지 안인가 |
| 스크립트 (`*.sh`, `*.py`) | 둘 다 가능 | 마운트인지 `COPY` 인지 |
| 의존성 (`go.mod`, `build.gradle`) | **재빌드** | - |
| 정적 리소스 (jar 안에 임베드) | **재빌드** | `embed.FS`, `src/main/resources` |

**애매하면 재빌드한다.** 재빌드는 느릴 뿐이고, 잘못 판정하면 옛 코드를 검증하게 된다.

## 반영 확인 - mtime 을 단독 근거로 쓰지 않는다

**재현성 빌드는 타임스탬프를 의도적으로 죽인다.**

```
build.gradle:255   '--sort=name', '--mtime=@0', '--owner=0', '--group=0', '--numeric-owner',
```

`--mtime=@0` 이 붙으면 새 바이너리를 풀어도 **mtime 이 1970 그대로**다.
실제로 이것 때문에 새 빌드를 배포하고도 타깃 버전이 옛 값에 고정돼 자동 업데이트가 아예 안 걸렸다
(`AgentVersionProvider.java:29-32` 의 주석이 이 사고를 기록하고 있다).

mtime 을 아예 버리라는 뜻이 아니다. 실제로 채택된 해법은 **`(mtime, size)` 조합 + 60초 TTL** 이었다
(`CACHE_TTL_MILLIS = 60_000L`). 단독으로 못 쓴다는 것이고, 보강하면 쓸 수 있다.

반영 확인은 아래 중 **최소 하나**로 한다. mtime 만 보지 않는다.

| 근거 | 명령 | 비고 |
|------|------|------|
| 내용 해시 | `md5sum` 로컬 vs 원격 | 가장 확실 |
| 버전 문자열 | `<bin> --version`, `/actuator/info`, `/version` | 바이너리가 스스로 답한다 |
| 이미지 태그 + 기동 시각 | `docker inspect --format '{{.Config.Image}} {{.State.StartedAt}}'` | `StartedAt` 이 방금인지 |
| 크기 | `stat -c %s` | mtime 보조용. 단독으로는 약함 |

**"파일을 보냈다" 는 반영의 증거가 아니다.** 그게 돌고 있다는 증거를 따로 잡는다.

## 재현성 빌드의 다른 부작용

`--sort=name --owner=0 --group=0 --numeric-owner` 도 같이 붙는다. 그래서:

- 파일 소유자·그룹이 전부 0(root) 으로 풀린다. 권한 기대가 다르면 문제가 된다
- 아카이브 순서가 고정돼 **내용이 같으면 해시도 같다** - 이건 반영 확인에 유리하다
- 반대로 **내용이 조금이라도 다르면 해시가 확실히 달라진다** - 그러니 해시 대조가 신뢰할 만하다
