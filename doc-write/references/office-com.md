# Word COM 으로 docx 만들기

Windows 에서 PowerShell 로 Word 를 COM 으로 불러 docx 를 만들거나 고칠 때의 순서와 함정이다.
아래 함정은 전부 실제 세션에서 걸린 것이다. Word 를 띄워 따로 시험한 것은 아니다.

## 1. 먼저 볼 것

| 순서 | 무엇 | 왜 |
|------|------|-----|
| 1 | **docx skill(`anthropic-skills:docx`)이 있으면 그쪽을 먼저 쓴다.** Word 를 띄우지 않고 파일을 직접 만든다 | Word COM 은 아래 함정이 많고 멈추면 시간을 크게 잃는다 |
| 2 | docx skill 이 없고 Word 가 깔린 Windows 면 이 문서대로 COM 을 쓴다 | |
| 3 | 둘 다 안 되면 SKILL.md 6절 docx 행대로 알리고 대체물을 쓸지 묻는다 | |

## 2. 함정

| 함정 | 어떻게 | 근거 |
|------|--------|------|
| 저장(`SaveAs2`)이 멈춘다 | **단계마다 로그를 파일에 남긴다** (열기, 고치기, 저장, 닫기 앞뒤). 멈추면 로그 마지막 줄로 어느 단계인지 보고 같은 명령을 그대로 다시 돌리지 않는다 | `SaveAs2` 가 멈춰 10분 타임아웃이 다섯 번 났다 |
| 한글 인자가 깨진다 | 한글 경로·문구를 명령줄 인자로 넘기지 않는다. **UTF-8 JSON 파일에 적고 스크립트가 그 파일을 읽는다** | PowerShell 에 넘긴 한글 인자가 깨졌다 |
| 경로를 못 받는다 | `Open`·`SaveAs2` 에 넘기는 경로는 `[string]` 으로 바꿔 넘긴다 | 경로를 `[string]` 으로 안 넘겨 실패했다 |
| 형식을 못 찾는다 | 스크립트가 쓰는 .NET 형식은 맨 앞에서 `Add-Type` 으로 싣는다 | `Add-Type` 이 빠져 실패했다 |
| 닫을 때 예외 | 문서를 `Close([ref]0)` 로 닫은 뒤 `Quit()` 를 인자 없이 부른다 | `Quit(0)` 에서 예외가 났다 |
| 변수가 덮인다 | **PowerShell 변수 이름은 대소문자를 가리지 않는다.** `$W` 와 `$w` 는 같은 변수다. Word 객체와 다른 값에 다른 낱말을 쓴다 (`$word`, `$doc`) | `$W`·`$w` 를 따로 쓰다 Word 객체가 덮였다 |
| 클라우드 동기화 폴더 (OneDrive 등) | 로컬 임시 폴더에 저장한 뒤 복사하고 md5 로 같은지 본다 (SKILL.md 저장 규칙) | SKILL.md 저장 규칙의 같은 행 |
| Word 가 남는다 | **띄우기 전후의 `WINWORD` PID 를 비교해 내가 띄운 PID 를 기록하고, `finally` 에서 그 PID 만 닫는다.** 이미 떠 있던 Word 는 끄지 않는다. 사용자에게 끄라고 넘기지 않는다 | 스스로 띄운 `WINWORD` 여섯 개가 남아 사용자에게 끄라고 넘겼다 |

## 3. 순서

| # | 할 일 |
|---|-------|
| 1 | 지금 떠 있는 `WINWORD` PID 를 적는다 (`Get-Process WINWORD -ErrorAction SilentlyContinue`) |
| 2 | 인자(원본 경로, 저장 경로, 넣을 글)를 UTF-8 JSON 파일로 쓴다 |
| 3 | 스크립트 파일을 만든다. 맨 앞 `Add-Type`, JSON 읽기, 단계마다 로그 |
| 4 | `try` 안에서 Word 를 띄우고 새로 생긴 PID 를 기록한다. 원본이 아니라 사본을 연다 (SKILL.md 6절) |
| 5 | 고친 뒤 로컬 임시 폴더에 `SaveAs2` 로 저장한다. 경로는 `[string]` |
| 6 | `Close([ref]0)`, `Quit()` |
| 7 | `finally` 에서 4번에 기록한 PID 가 아직 있으면 그것만 끝낸다 |
| 8 | 결과 파일을 산출물 폴더로 복사하고 md5 를 비교한다. 1번에 없던 `WINWORD` 가 남았는지 다시 본다 |
