# 쓰기 규칙

규칙마다 근거를 단다. 근거는 사용자 발화 원문이거나, 원문이 남지 않은 세션 교정이다.
발화가 받쳐 주는 범위를 넘겨 넓힌 것은 `(판단)` 으로 표시한다.
규칙 문구가 근거보다 넓어져 "무슨 근거로 정한가냐고" 를 들은 적이 있어서다.

인용 안의 기관·제품 이름은 `<기관>` 처럼 바꿨다.

## 3. 남에게 넘기는 문서에서 뺄 것

`~/.claude/skills/shared/references/reporting.md` 5절을 따른다. 요지만 둔다.

| 물음 | 아니면 |
|------|--------|
| 이 문단으로 읽는 사람에게 할 일이 생기나 | 뺀다 |
| 이 사람이 정할 수 있는 것인가 | 정할 사람이 따로 있으면 `고려 대상` 이라고만 |
| 이 문단이 읽는 사람이 판단할 재료인가 | 별도 파일로 뺀다. 내가 확인 못 한 것이 여기 걸린다 |
| 내 조사 과정·수치를 다시 뽑는 법인가 | 뺀다 |

읽는 사람이 손을 움직일 사람이면 할 일로 쓴다 ("됩니다. 하세요. 어투로 고쳐").

## 4. 공개 문서

| 규칙 | 근거 |
|------|------|
| **공개 문서는 내부 이름·사내 경로·IP·계정을 뺀다.** 문서와 그림 원본을 내부 이름 목록으로 grep 해 0건을 확인한다 | "소스적인 부분 다 빼고 그냥 앞으로 어떻게 할건지 얘기만 적자 그러면 완전히 공개해도 문제 될꺼 없으니까" |
| **그림·캡처 속 글자는 grep 에 안 잡힌다.** 하나씩 눈으로 본다. 이름이 찍힌 캡처는 **이미지 파일 자체에서 그 픽셀을 지운 판**(다시 찍거나 잘라 내거나 칠한 PNG)으로 바꿔 넣는다. 슬라이드·문서 위에 도형을 덮는 것으로 끝내지 않는다. 덮어도 원본 이미지가 `ppt/media/`·`word/media/`·`BinData/` 에 그대로 남는다 | 워크샵 자료에서 화면 19장을 눈으로 본 일 (원문 미보존), 외부 리뷰 |
| **화면에 안 보이는 곳도 공개된다.** 공개본을 내기 전에 본다: pptx 슬라이드 노트·숨긴 슬라이드·숨긴 개체·`media/` 의 모든 이미지, docx 메모·변경 내용·`media/`, hwp/hwpx 메모·지운 글·머리말·꼬리말 (`hwp.md` 5절). 못 본 곳은 "확인 못 함" 으로 보고한다 | 외부 리뷰 |
| **작업본과 공개본을 나눈다.** 메모·변경 추적·원본 캡처가 남은 작업본을 그대로 공개하지 않는다. 공개본은 따로 만들고 위 검사를 그 파일에 한다 | 외부 리뷰 |
| **써도 되는 이름은 사용자가 정한다.** 회사 이름처럼 남겨도 되는 것을 내가 지우지 않는다 | "<회사> 라고 쓰면 돼" |
| 다른 과제 이름을 쓰지 않기로 한 자료는 기능 이름으로 쓴다 ("인프라 그룹 관리", "연동 계층", "기반 오픈소스"). 지시받지 않고 적용했으면 그렇다고 밝힌다 | 과제 회의에서 정한 표기 규칙을 따른 일, 다른 문서에 임의 적용하고 밝힌 일 |
| PR 본문에 `## Summary`, `## Test plan`, 체크박스, 생성 도구 문구를 쓰지 않는다 | 전역 규칙 (`CLAUDE.md` PR 절) |

## 6. 형식과 고치는 방식

| 규칙 | 근거 |
|------|------|
| **출력 형식 말은 그대로 따른다.** "txt" 면 txt, "계단식" 이면 `-` 들여쓰기 목록, "뽑아" 면 파일 | "아아 md 말고 txt", "- 를 써서 계단식으로 해줄래? 펴 말고" |
